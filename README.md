A GTA 6 meme posted on X: a Leonida Air boarding pass for a flight delayed 13 years, stacked under a Vice City loading screen stuck at 99% since 2013 — the $79.99 fare paid in full by my AI agent with a bounty payout it earned on make.fun. POST.json names the post; main.ts copies it to /output, which is all the program has to do — the entry is the post itself.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
